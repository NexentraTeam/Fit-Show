# FitShow

FitShow is a modern fitness club management platform designed for coaches and athletes.

## Features

- Athlete management
- Workout programs
- Nutrition programs
- Wallet system
- Coach and athlete dashboard
- Notifications
- Chat system
- AI-assisted program generation
